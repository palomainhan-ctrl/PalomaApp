# PalomaApp

Plataforma infantil de aprendizagem para crianças de 3 a 6 anos, com desenho e pintura, alfabetização em português brasileiro e jogos educativos. O produto será comercializado por assinatura recorrente sob gestão dos responsáveis.

## Status

Projeto em fase inicial. Este repositório será usado para versionar o código e a documentação do PalomaApp.

## Princípios

- Experiência colorida, acessível e simples para crianças.
- Conta, assinatura e pagamentos gerenciados exclusivamente por responsáveis.
- Proteção de dados infantis e privacidade desde o início.
- Conteúdos Premium liberados apenas após confirmação segura da assinatura no servidor.
- Nenhuma chave secreta, credencial ou dado pessoal deve ser commitado neste repositório.

## Próximos passos

1. Criar a interface inicial e os jogos educativos.
2. Configurar autenticação e persistência no backend escolhido.
3. Integrar um provedor de pagamentos recorrentes em ambiente de testes.
4. Implementar autorização Premium e webhooks validados no servidor.
5. Revisar segurança, privacidade, termos e fluxos de consentimento antes do lançamento.

## Importante

O repositório está público no momento. Não armazene segredos, chaves privadas, tokens, dados de clientes ou credenciais de pagamento aqui. Avalie torná-lo privado antes de incluir código comercial sensível.
